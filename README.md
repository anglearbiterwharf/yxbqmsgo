# LJT-Homepage

Personal academic homepage of Junteng Liu, prepared from the academicpages template.

This repository holds the contents of the `LJT-Homepage` personal site: the homepage (`_pages/about.md`), site configuration (`_config.yml`), author data (`_data/authors.yml`), navigation (`_data/navigation.yml`) and the publications collection (`_publications/` + `_pages/publications.html`).
